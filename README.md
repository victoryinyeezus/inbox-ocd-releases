# Inbox OCD Releases

Installers and the automatic-update feed for **Inbox OCD**, the unified Gmail + Outlook desktop app.

**[Download the latest release](https://github.com/victoryinyeezus/inbox-ocd-releases/releases/latest)**

## Which file do I need?

| Computer | File |
|---|---|
| Mac with Apple silicon (M1 or newer), macOS 11 or later | `Inbox.OCD_<version>_aarch64.dmg` |
| Windows 10 or 11, 64-bit | `Inbox.OCD_<version>_x64-setup.exe` |

Intel Macs are not supported. Windows on ARM PCs can run the x64 installer.

The other files (`latest.json`, `Inbox.OCD.app.tar.gz`, and the `.sig` files) are used by the app's built-in updater. You don't need to download them.

## Updates

Installed copies check `releases/latest/download/latest.json` in this repository and update themselves. This repository was previously named `gridline-releases`; GitHub redirects the old address, so older installs keep updating. Older releases keep their original file names.

More at [inboxocd.com](https://inboxocd.com).
